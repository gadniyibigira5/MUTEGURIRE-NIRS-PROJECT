# Problem and solution

## Problem

Maternal and child health indicators, socioeconomic context, and population information can be published in separate reports and at different geographic levels. A district planner who needs to compare local needs may have to find, reconcile, and interpret these sources manually. Missing or non-comparable figures make prioritization harder and can create a false impression of certainty when shown without context.

## Intended users

- District health planners and public-health analysts.
- Programme coordinators reviewing outreach capacity and service coverage.
- Researchers and students exploring district-level patterns.
- Reviewers who need to understand where evidence is incomplete before drawing conclusions.

These are intended user groups, not a claim that the tool has been formally adopted by any institution.

## Solution

Mutegurire provides one interactive district-level view for selected maternal and child health indicators and socioeconomic context. Users can inspect a district, compare available indicators, view a ranking for the selected indicator, explore descriptive changes where both time points exist, and test an illustrative outreach-capacity scenario.

The dashboard surfaces data-quality statuses. A missing value remains missing; a proxy is labelled as a proxy; and a derived burden estimate is not presented as an official count. The assistant can answer supported questions from the dashboard data and help users locate relevant comparisons. PDF import is a candidate-extraction aid: a person must verify the extracted value against the source report before any update is published.

## Decision workflow

1. **Explore:** choose an indicator and inspect district coverage.
2. **Inspect:** open a district profile and read values together with their statuses and caveats.
3. **Compare:** compare districts or look for broad patterns without assuming causation.
4. **Plan a scenario:** test an illustrative distribution of outreach capacity.
5. **Review evidence:** inspect the source and reporting period, and record unresolved gaps.
6. **Decide outside the tool:** combine the dashboard with domain expertise, current local data, feasibility, community input, and programme evaluation.

## Expected value

The prototype is intended to reduce the time needed to assemble an initial comparative view and make evidence gaps visible early. This is an intended benefit; no measured time saving, health impact, or intervention effectiveness is claimed yet.

## Boundaries

Mutegurire does not diagnose individuals, recommend contraception to individuals, forecast mortality, establish causal drivers, prove which intervention works, or make automatic funding decisions. Any family-planning discussion should be rights-based and focus on voluntary access and unmet need, never coercive fertility targets or assumptions about poorer families.
