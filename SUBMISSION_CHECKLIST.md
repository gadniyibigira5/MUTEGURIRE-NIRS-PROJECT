# Mutegurire submission checklist

Complete this file against the final public release. Do not mark an item done until it has actually been checked.

## Required submission items
- [ ] Public GitHub repository URL recorded.
- [ ] Public deployed application URL recorded and tested in a private window.
- [ ] Documentation links checked from README.
- [ ] Source citations and dataset licences checked.
- [ ] AI use disclosed.
- [ ] Team reviewed the originality declaration and competition terms.
- [ ] Demo video recorded and linked (if required or useful).

## Technical checks
- [ ] `npm install` succeeds from a clean checkout.
- [ ] `npm run build` succeeds.
- [ ] District map, selection, ranking, profiles, insight view, language toggle, and theme toggle tested.
- [ ] Missing and proxy values are clearly labelled.
- [ ] If API deployed: `/api/health`, chat, fallback, CORS, and PDF preview tested.
- [ ] No secret, local virtual environment, `node_modules`, or raw restricted file committed.

## Data integrity checks
- [ ] No unsupported number added to fill a gap.
- [ ] Each publicly claimed statistic has source publication, page/table, year, definition, and denominator recorded.
- [ ] Derived/proxy estimates are labelled as such.
- [ ] Current NST2 target wording and year verified from the primary document or omitted.
